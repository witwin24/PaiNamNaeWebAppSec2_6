# User Manual
เอกสารนี้จะอธิบายการใช้งานของระบบที่เพิ่มเข้ามา

## 1. การลบบัญชีผู้ใช้
ผู้ใช้สามารถทำการลบบัญชีของตนเองออกจากระบบได้เมื่อไม่ต้องการใช้งานอีกต่อไป
*หมายเหตุ: ในส่วนของการลบบัญชี ข้อมูลส่วนตัวจะถูกลบตามนโยบายความเป็นส่วนตัวของระบบ แต่ Log การทำรายการจะยังคงถูกเก็บรักษาเป็นเวลา 90 วัน ตามกฎหมาย

### ขั้นตอนการดำเนินการ
1. ผู้ใช้ทำการเข้าสู่ระบบด้วยบัญชีที่ต้องการลบ
2. เมื่อล็อกอินสำเร็จ ระบบจะพามาที่หน้าหลัก ให้ทำการกดที่รูปโปรไฟล์จะมีเมนู Drop-down ลงมา
3. กดปุ่ม "บัญชีของฉัน" เพื่อไปที่หน้าตั้งค่าโปรไฟล์
4. ที่แถบเมนูโปรไฟล์และการตังค่า ไปที่การจัดการบัญชี กดปุ่ม "ลบบัญชีของฉัน" เพื่อไปที่หน้ายืนยันการลบบัญชี
5. ที่หน้ายืนยันการลบบัญชี ให้กรอกรหัสผ่านของบัญชีผู้ใช้ปัจจุบันที่เข้าสู่ระบบอยู่
6. กดปุ่ม "ยืนยันการลบ" หากลบสำเร็จระบบจะแสดงหน้าต่างแจ้งเตือนว่า "ลบบัญชีสำเร็จ"
7. กดปุ่ม "ตกลง" จะถือว่าการลบบัญชีผู้ใช้เสร็จสิ้นจากนั้นระบบจะทำการออกจากระบบและกลับไปที่หน้าหลัก

## 2. การบันทึกกิจกรรมของระบบ
เพื่อให้เป็นไปตามกฏหมาย ระบบมีการบันทึกกิจกรรมที่สำคัญ (Logging) ไว้ในฐานข้อมูลโดยอัตโนมัติ

### รายละเอียดการทำงาน
ในส่วนนี้เป็นการทำงานของระบบ Backend ซึ่ง**ไม่มีหน้าจอ UI** แต่จะมีการบันทึกข้อมูลลงในฐานข้อมูลเมื่อมีการลบบัญชีเกิดขึ้น ดังนี้

| Field | คำอธิบายข้อมูล | ตัวอย่างข้อมูล |
| :--- | :--- | :--- |
| **User** | รหัสผู้ใช้งาน หรือ ชื่อผู้ใช้งาน | `user_12345` |
| **Method** | รูปแบบการเรียกใช้งาน HTTP | `DELETE`, `POST`, `GET` |
| **Endpoint** | เส้นทางของ API ที่ถูกเรียก | `/api/bookings/me` |
| **Status** | รหัสสถานะการตอบกลับ (HTTP Status) | `200`, `400` |
| **IP Address** | ที่อยู่ไอพีของผู้เรียกใช้งาน | `10.x.x.x` |
| **User Agent** | ข้อมูล Browser หรือ อุปกรณ์ที่ใช้ | `Mozilla/5.0...` |
| **Timestamp** | วันและเวลาที่เกิดรายการ | `2026-02-17T12:00:00Z` |

### การเข้าถึงข้อมูล Log
- ข้อมูลส่วนนี้จำกัดสิทธิ์การเข้าถึงเฉพาะ **ผู้ดูแลระบบ** ผ่านการตรวจสอบ Database โดยตรงเท่านั้น
- ใช้สำหรับตรวจสอบย้อนหลังในกรณีที่เกิดปัญหาทางเทคนิคหรือข้อพิพาทด้านข้อมูล
