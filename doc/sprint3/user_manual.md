## 1. การลบบัญชีผู้ใช้
ผู้ใช้สามารถทำการลบบัญชีของตนเองออกจากระบบได้เมื่อไม่ต้องการใช้งานอีกต่อไป
*หมายเหตุ: ในส่วนของการลบบัญชี ข้อมูลส่วนตัวจะถูกลบตามนโยบายความเป็นส่วนตัวของระบบ แต่ Log การทำรายการจะยังคงถูกเก็บรักษาเป็นเวลา 90 วัน ตามกฎหมาย

### ขั้นตอนการดำเนินการ
1. ผู้ใช้ทำการเข้าสู่ระบบด้วยบัญชีที่ต้องการลบ
2. เมื่อล็อกอินสำเร็จ ระบบจะพามาที่หน้าหลัก ให้ทำการกดที่รูปโปรไฟล์จะมีเมนู Drop-down ลงมา
3. กดปุ่ม "บัญชีของฉัน" เพื่อไปที่หน้าตั้งค่าโปรไฟล์
4. ที่แถบเมนูโปรไฟล์และการตังค่า ไปที่การจัดการบัญชี กดปุ่ม "ลบบัญชีของฉัน"
5. จะมีหน้าต่างขึ้นมาเพื่อสอบถามข้อมูลที่ต้องการจะรับ เพื่อระบบจะได้นำข้อมูลเหล่านั้นส่งเป็น Zip file ส่งไปที่อีเมลของบัญชีผู้ใช้ต่อไป
    ข้อมูลที่สามารถเลือกรับได้ประกอบไปด้วย
        - ข้อมูลส่วนตัว (ชื่อ, อีเมล, เบอร์โทรศัพท์ และข้อมูลบัญชี)
        - ข้อมูลใบขับขี่* (ข้อมูลการยืนยันตัวและใบขับขี่)
        - ข้อมูลยานพาหนะ* (รายละเอียดรถและทะเบียนยานพาหนะ)
        - ประวัติเส้นทาง* (เส้นทางและการเดินทางที่สร้างไว้ทั้งหมด)
        - ประวัติการจอง* (รายการจองที่เคยทำทั้งหมด)
        *หมายเหตุ: ตัวเลือกดังกล่าวจะปรากฎให้เลือกก็ต่อเมื่อระบบพบข้อมูลในระบบ หากบัญชีดังกล่าวไม่มีข้อมูลเหล่านั้นในระบบ จะไม่พบตัวเลือกดังกล่าว
        **หากผู้ใช้ไม่ทำการติ๊กถูกในตัวเลือกข้อมูลที่จะรับใดๆเลย ข้อมูลบัญชีผู้ใช้จะยังคงถูกลบแต่จะ ไม่มีการส่งข้อมูลบัญชีผู้ใช้ไปที่อีเมล**
    เมื่อผู้ใช้กดติ๊กถูกในตัวเลือกข้อมูลที่ต้องการจะรับเสร็จแล้ว ให้กดปุ่ม "ถัดไป" จะพบกับหน้ายืนยันการลบบัญชี
6. ที่หน้ายืนยันการลบบัญชี ให้ผู้ใช้ทำการกรอกรหัสผ่านของบัญชีผู้ใช้ปัจจุบันที่เข้าสู่ระบบอยู่
7. กดปุ่ม "ยืนยันการลบ" หากลบสำเร็จระบบจะแสดงหน้าต่างแจ้งเตือนว่า "ลบบัญชีสำเร็จ ข้อมูลของคุณได้ถูกส่งไปยัง Email แล้ว" หรือในกรณีที่ผู้ใช้ไม่ได้เลือกตัวเลือกใดๆในข้อ 5 จะแสดงหน้าต่างแจ้งเตือนว่า "ลบบัญชีสำเร็จ ข้อมูลของคุณจะไม่ถูกส่งไปยัง Email เนื่องจากคุณไม่ได้เลือกข้อมูลใดๆ ในขั้นตอนก่อนหน้า"
    7.1 หากผู้ใช้ไม่กรอกรหัสผ่าน จะมีหน้าต่างแจ้งเตือนว่า "กรุณากรอกรหัสผ่าน" ให้ผู้ใช้กดตกลงและทำการกรอกรหัสผ่านของบัญชีผู้ใช้ในช่องกรอกรหัสผ่าน
    7.2 หากผู้ใช้กรอกรหัสผ่านผิด จะมีหน้าต่างแจ้งเตือนว่า "ลบไม่สำเร็จ: รหัสผ่านไม่ถูกต้อง" ให้ผู้ใช้กดตกลงและทำการกรอกรหัสผ่านของบัญชีผู้ใช้ที่ถูกต้องในช่องกรอกรหัสผ่าน
8. กดปุ่ม "ตกลง" จะถือว่าการลบบัญชีผู้ใช้เสร็จสิ้นจากนั้นระบบจะทำการออกจากระบบและกลับไปที่หน้าหลัก
และมีการส่ง Zip File ไปที่อีเมลของบัญชีผู้ใช้ ตามตัวเลือกที่ผู้ใช้ได้เลือกไว้ในข้อ 5

## การดำเนินการกับ Zip File หลังลบบัญชีผู้ใช้
หากผู้ใช้มีการเลือกรับข้อมูลบัญชีผู้ใช้ใดๆหลังลบบัญชี จะมีอีเมลหัวเรื่อง "Your Account Data Export - PaiNamNae" จาก 
PaiNamNae Support Team<noreply@csse2669.me> ส่งไปที่อีเมลของบัญชีผู้ใช้ที่ทำการลบ โดยผู้ใช้สามารถดาวน์โหลด Zip file ข้อมูลบัญชีเหล่านั้นได้

### ขั้นตอนการดำเนินการ
1.ไปที่อีเมลของผู้ใช้ เช่น example@gmail.com
2.หาอีเมลหัวเรื่อง "Your Account Data Export - PaiNamNae" ที่ส่งมาจาก PaiNamNae Support Team<noreply@csse2669.me>
3.เข้าไปที่เมลดังกล่าว แล้วทำการดาวน์โหลดไฟล์แนบ user_data_export.zip ที่อยู่ในเมล ข้อ 2 ลงไปที่เครื่องของผู้ใช้
4.ที่เครื่องของผู้ใช้ให้ทำการใช้ WinRAR หรือ 7-Zip ทำการแตกไฟล์ user_data_export.zip โดยการคลิกขวาที่ไฟล์ user_data_export.zip และเลือก Extract Here
5.เมื่อแตกไฟล์เสร็จสิ้นจะพบไฟล์ csv ที่เก็บข้อมูลบัญชีของผู้ใช้ไว้ ผู้ใช้สามารถเปิดดูได้ด้วยโปรแกรม Microsoft Excel, Notepad++ หรือโปรแกรมอื่นๆที่เกี่ยวข้อง โดยไฟล์ csv ที่จะพบใน user_data_export.zip มีดังนี้
    - user_data.csv *กรณีผู้ใช้เลือกรับ ข้อมูลส่วนตัว
    - driver_verification.csv *กรณีผู้ใช้เลือกรับ ข้อมูลใบขับขี่
    - route_history.csv *กรณีผู้ใช้เลือกรับ ประวัติเส้นทาง
    - vehicles_data.csv *กรณีผู้ใช้เลือกรับ ข้อมูลยานพาหนะ
    - booking_history.csv *กรณีผู้ใช้เลือกรับ ประวัติการจอง

## 2. การบันทึกกิจกรรมของระบบและการส่งออกข้อมูลกิจกรรม
เพื่อให้เป็นไปตามกฏหมาย ระบบมีการบันทึกกิจกรรมที่สำคัญ (Logging) ไว้ในฐานข้อมูลโดยอัตโนมัติ และมีการส่งออกข้อมูลเพื่อให้สามารถนำข้อมูลไปใช้ด้านกฏหมาายต่อได้

### รายละเอียดการทำงาน
ในส่วนนี้เป็นการทำงานของระบบ Backend ซึ่ง**ไม่มีหน้าจอ UI** แต่จะมีการบันทึกข้อมูลลงในฐานข้อมูลเมื่อมีการลบบัญชีเกิดขึ้น ดังนี้

| Field | คำอธิบายข้อมูล | ตัวอย่างข้อมูล |
| :--- | :--- | :--- |
| **User** | รหัสผู้ใช้งาน หรือ ชื่อผู้ใช้งาน | `user_12345` |
| **Method** | รูปแบบการเรียกใช้งาน HTTP | `DELETE`, `POST`, `GET` |
| **Endpoint** | เส้นทางของ API ที่ถูกเรียก | `/api/bookings/me` |
| **Status** | รหัสสถานะการตอบกลับ (HTTP Status) | `200`, `400` |
| **IP Address** | ที่อยู่ไอพีของผู้เรียกใช้งาน | `10.x.x.x` |
| **User Agent** | ข้อมูล Browser หรือ อุปกรณ์ที่ใช้ | `Mozilla/5.0...` |
| **Timestamp** | วันและเวลาที่เกิดรายการ | `2026-02-17T12:00:00Z` |

### การเข้าถึงข้อมูล Log
- ข้อมูลส่วนนี้จำกัดสิทธิ์การเข้าถึงเฉพาะ **ผู้ดูแลระบบ** ผ่านการตรวจสอบที่หน้า Traffic Log และ Export Log
- ใช้สำหรับตรวจสอบย้อนหลังในกรณีที่เกิดปัญหาทางเทคนิคหรือข้อพิพาทด้านข้อมูล

## การ Export Log
1. เข้าสู่ระบบด้วยบัญชีแอดมิน
2. ไปที่หน้า Dashboard
3. ไปที่ Traffic Log แล้วกด Export
4. ใส่รหัสผ่านเพื่อยืนยันตัวตน
5. จะได้ไฟล์ zip ออกมา โดยจะมี 3 ไฟล์ คือ .json (เก็บ Log), .sha256 (เก็บ hash) และ .bat (สคริปต์ในการเช็คว่าไฟล์ Log มีการแก้ไขหรือไม่)

## ตรวจสอบว่าไฟล์ Log มีการเปลี่ยนแปลงหรือไม่
1. ทำการแตกไฟล์ zip
2. เข้าไปที่ Folder ที่แตกไฟล์มา
3. ดับเบิ้ลคลิก verify-log.bat เพื่อตรวจสอบ
4. หากไม่มีการเปลี่ยนแปลง จะขึ้นข้อความว่า " VALID FILE (No Modification) " แต่หากมีการเปลี่ยนแปลง จะขึ้นข้อความว่า " FILE TAPERED! "
